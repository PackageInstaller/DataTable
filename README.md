# DataTable

`master` 只保留索引和 git 相关文件，每个游戏一个独立的快照分支（`game/<游戏名>`），方便只拉取自己需要的数据。

## 克隆单个游戏

```bash
git clone -b game/AnchorPanic --single-branch --depth 1 https://github.com/PackageInstaller/DataTable.git
```
